Girly Girl Skincare Diary 🎀

Это готовые статические файлы PWA. Никаких платных сервисов и API нет.

Чтобы установить на iPhone:
1. Разместите содержимое этой папки на бесплатном HTTPS-хостинге (например, GitHub Pages или Cloudflare Pages). Загружать нужно файлы из папки, а не ZIP как один файл.
2. Откройте адрес в Safari на iPhone, дождитесь первой полной загрузки.
3. Нажмите «Поделиться» -> «На экран Домой» -> «Добавить».
4. После первой загрузки и установки приложение работает без сети. Данные отметок сохраняются локально в браузере.

Для проверки на компьютере: из папки выполните python3 -m http.server 8000 и откройте http://localhost:8000.

Внимание: при очистке данных сайта Safari записи могут исчезнуть. В настройках приложения есть экспорт и импорт JSON.

План активов ориентировочный, не заменяет рекомендации врача. Начальная дата по умолчанию 03.11.2026, ее можно поменять в настройках. Не увеличивайте частоту при раздражении. Адапален противопоказан при беременности и ее планировании.
